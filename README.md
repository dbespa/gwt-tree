# Проект

## Задание
Разработать клиент-серверное приложение редактирования древовидной структурой. Дерево - это набор вкладываемых равноправных узлов, в любой узел можно положить любое количество узлов. Каждый узел также содержит дополнительные данные.

## Функционал
- Просмотреть таблицу узлов
- Просмотреть дерево


## Сборка
```bash
ant devmode
```
