# Проектирование: Дерево

## Потребители

Клиент

## Use Case

- **Я как** Клиент **хочу** просмотреть список с информацией о каждом узле дерева из хранилища **чтобы** проверять дерево с фактическими данными в базе 
- **Я как** Клиент **хочу** обновить список с информацией об узлах дерева **чтобы** иметь актуальные данные о дереве

## Существительные и глаголы

### Существительные

- Узел
- Дерево
- Список
- Хранилище

### Глаголы

- Просмотреть
- Обновить
